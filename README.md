# 🐣 Poekie

A Tamagotchi-style virtual pet built with React Native.

## 📖 About

Poekie is a virtual pet game inspired by the classic Tamagotchi. Take care of your pet by keeping it healthy, fed, and happy as its status changes over time.

The app uses Zustand for state management and AsyncStorage for persistence, allowing the pet's condition to continue evolving even while the app is closed. A dynamic ASCII face visually reflects the pet's current mood and condition.

## ✨ Features

* 🐣 Tamagotchi-inspired gameplay
* ⏳ Real-time pet status updates
* 💾 Persistent game state with AsyncStorage
* 🗂️ State management with Zustand
* (^_^), (T_T), (x_x)... Dynamic ASCII face based on the pet's condition
* 📱 Clean and responsive interface

## 🚀 Getting Started

### Prerequisites

* Node.js
* Expo CLI

### Installation

```bash
git clone https://github.com/brunols7/poekie-pet.git

cd poekie-pet

npm install

npx expo start
```
